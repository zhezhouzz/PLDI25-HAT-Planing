%   Functional programs typically interact with effectful libraries that
%   hide state behind typed abstractions.  Not suprisingly, the

%   specific client.  Consequently, applications often must implement
%   their own \emph{ad hoc} protocols that impose additional constraints
%   on this state, indirectly, in terms of call (and return) sequences
%   to (and from) library methods.  In this paper, we consider the
%   specification and verification of such protocols using
%   \emph{symbolic finite automata} (SFA).  We show that SFAs can be

%   protocols over functions that internally make calls to effectful
%   library methods.  A HAT characterizes the behavior of such functions

%   structure that must hold at any of its call points immediately prior
%   to its invocation, as well as postcondition ones, i.e., the portion

%   methods invoked by the function as it executes.  We also develop a
%   new bidirectional type checking algorithm that implements an
