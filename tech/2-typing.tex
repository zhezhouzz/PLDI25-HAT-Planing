\paragraph{Strong Consistency} The SC requires that when the user receive the read response, the read value is the same as the current database, which can be expressed as the following \PAT:
{\footnotesize
  \begin{align*}
    &\effLR{\finalA \msg{putReq}{k = \Code{key} \land v = \Code{val}} \land \nextA \neg \finalA \msg{putReq}{k = \Code{key}} } %
    \\& \quad \effLR{\lastA \msg{getReq}{k = \Code{key}}}%
    \effLR{(\neg \msg{putReq}{k = \Code{key}}) \untilA \msg{getRsp}{k = \Code{key} \land v = \Code{val}}}
\end{align*}}\noindent
whose prophecy automata indicates that there is no no updates ($\eff{putReq}$) happens before the user receives the read value.
